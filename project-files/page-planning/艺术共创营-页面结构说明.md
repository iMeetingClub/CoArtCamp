# 艺术共创营活动页结构说明

## 1. 文档用途

本文档用于指导“艺术共创营”移动端活动页的前端设计与开发。
当前文档面向开发者与内部整理人员使用，不是最终对外发布文案，因此允许大部分具体文案、图片、人员信息、作品信息先留空或使用占位内容。

---

## 2. 项目目标

本活动页是一个以移动端为主的纯前端专题页，用于展示“艺术共创营”的整体活动介绍、历期内容与第三期重点成果。

页面整体气质要求如下：

- 不要刻板，不要像传统政务或企业官网
- 要有留白、呼吸感和展览感
- 以叙事氛围为主，整体更像“艺术活动导览页”
- 信息要清楚，但不要堆砌
- 页面以图片、主题文字、节奏感布局来建立气质

---

## 3. 页面组成

整个活动页由以下页面组成：

1. 活动首页
2. 第一期详情页
3. 第二期详情页
4. 第三期主详情页
5. 第三期共创故事页

---

## 4. 全站统一设计规则

### 4.1 设备优先级

- 优先适配手机移动端
- 采用单列纵向浏览方式
- 所有主要信息以滑动阅读为主

### 4.2 全站导航方式

全站统一使用左上角“侧边栏按钮”作为导航入口。

#### 按钮位置

- 位于每个页面左上角
- 放在页面顶部安全区域内
- 优先靠左，不与主标题抢占视觉中心

#### 按钮作用

点击后打开左侧抽屉式侧边栏导航。

#### 侧边栏关闭方式

- 点击左上角按钮再次关闭
- 点击页面遮罩关闭
- 左滑关闭

### 4.3 侧边栏内容

侧边栏中包含以下页面入口：

- 活动首页
- 第一期
- 第二期
- 第三期
- 共创故事

当前页面所在项需要高亮显示。

---

## 5. 活动首页结构

活动首页是用户进入后首先看到的页面，主要承担以下功能：

- 让用户快速知道“艺术共创营”是什么
- 呈现整体气质与活动氛围
- 展示历期内容入口
- 展示第四期规划信息
- 在结尾补充工作人员信息

---

## 6. 活动首页详细布局

### 6.1 顶部导航区

#### 位置

页面最上方。

#### 内容

- 左上角：侧边栏按钮
- 右上角：默认不放操作按钮

#### 说明

顶部导航区不要做成过重的传统标题栏，应尽量轻，给首屏留出呼吸空间。

#### 位置草图

```text
┌──────────────────────────────┐
│ 左上：侧边栏按钮              │
│                              │
│                右上留白       │
└──────────────────────────────┘
```

---

### 6.2 Banner 首屏区

#### 位置

导航区下方，首页第一屏最核心位置。

#### 内容

- 活动名称：艺术共创营
- 一句活动引导语
- 一张主视觉图或氛围图

#### 布局建议

- 活动名称放在视觉中心或偏下区域
- 引导语放在活动名称下方
- 主视觉图作为首屏氛围主图
- 不要在首屏堆太多字

#### 作用

先建立活动气质，再进入信息说明。

#### 位置草图

```text
┌──────────────────────────────┐
│ 左上：侧边栏按钮              │
│                              │
│ 艺术共创营                    │
│ 一句活动引导语                │
│                              │
│ [ Banner 主视觉图 / 氛围图 ]  │
└──────────────────────────────┘
```

---

### 6.3 活动介绍区

#### 位置

Banner 下方。

#### 内容

需要包含以下信息：

- 艺术共创营是什么
- 以共创方式开展活动
- 目前已举办三期
- 第三期正在进行中
- 后续还将开展第四期

#### 布局建议

- 上方为区块标题，例如“活动介绍”
- 下方为一段或两段简短说明文字
- 文字长度不宜过长，优先短段落

#### 位置草图

```text
┌──────────────────────────────┐
│ 活动介绍                      │
│                              │
│ 这里放活动背景、共创方式、    │
│ 已举办三期、第三期进行中、    │
│ 第四期规划等说明内容          │
└──────────────────────────────┘
```

---

### 6.4 历期入口区

#### 位置

活动介绍区下方。

#### 区块标题

建议使用“历期共创营”或“历期回顾”。

#### 结构说明

首页中的每一期入口不是简单“上图下文”，而是使用更有设计感的横向编排结构。
每一期入口由三部分组成：

1. 主图区域
2. 主题文字窄栏区域
3. 下方详细介绍区域

#### 共同交互方式

- 每一期入口整块可点击
- 点击后进入对应期数详情页
- 不单独设置“查看详情”按钮

#### 区块位置草图

```text

│                              │
```

## 7. 首页历期入口详细排列规则

### 7.1 第一期入口

#### 布局方式

- 图片放在左侧
- 主题文字窄栏放在右侧
- 这一横排下方是本期标题和详细介绍

#### 横排上方区域结构

- 左侧约占主要宽度：放第一期主图
- 右侧约占较窄宽度：放“01”、主题词、单期辅助图、短句等内容

#### 下方内容区

- 第一行：第一期标题
- 第二行：一句本期主题说明
- 第三行及以下：本期简要介绍

#### 作用

作为历期入口中的第一张卡，建立节奏起点。

#### 位置草图

```text
┌──────────────────────────────┐
│ 第一期                        │
│                              │
│ ┌──────────────────────┐ ┌──┐│
│ │ 第一期主图           │ │01││
│ │                      │ │主││
│ │                      │ │题││
```

### 7.4 第四期规划入口

#### 内容文案

第四期固定显示：

`规划中，敬请期待`

#### 布局方式

第四期不进入正式详情页，可作为一个“规划中”区块放在历期入口的最后。

#### 结构建议

- 不强制放完整主图
- 可以放一个较轻的占位图、留白块、线框块或计划中视觉占位
- 下方文字明确写“规划中，敬请期待”

#### 作用

让用户知道活动不是结束于第三期，而是仍在继续。

#### 位置草图

```text
┌──────────────────────────────┐
│ 第四期                        │
│                              │
│ [ 占位图 / 计划中视觉区 ]     │
│                              │
│ 规划中，敬请期待              │
└──────────────────────────────┘
```

---

### 7.5 历期区整体节奏要求

- 各期之间要有明显留白
- 第一、第二、第三期形成左右交替错落
- 不做过密卡片堆叠
- 文字大小必须保证移动端可读
- 视觉错落感主要通过左右交替、图片比例、窄栏主题区和留白实现

### 8.1 位置

## 9. 分期详情页统一规则

第一期、第二期、第三期的详情页都遵循统一的基础逻辑：

1. 左上角有侧边栏按钮
2. 页面顶部有本期标题区
3. 内容按纵向滚动展示
4. 详情页中的图片编排延续首页的左右错落逻辑
5. 每个内容模块之间要有明显间距和节奏

## 15. 开发说明重点

开发时需要特别注意以下几点：

- 页面不是普通资讯列表页，而是有展览编排感的活动专题页
- 首页历期入口必须采用左右错落布局
- 第一期为图左文右，第二期为图右文左，第三期再回到图左文右
- 各期详情页中的作品展示也按左右交替排列
- 第四期在首页显示“规划中，敬请期待”
- 整站统一使用左上角侧边栏按钮进行页面切换
- 第三期不使用 tab 切换结构，而是采用“主详情页 + 共创故事独立页”的结构
