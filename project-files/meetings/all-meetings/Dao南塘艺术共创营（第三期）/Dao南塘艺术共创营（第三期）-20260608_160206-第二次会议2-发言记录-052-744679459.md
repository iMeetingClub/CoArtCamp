    一、核心想法
    本次分组采用【自荐队长+主题前置+自主选组】的模式，核心是以兴趣和目标为导向，兼顾主动性与效率：
    1. 自荐队长能为小组提供明确的负责人与方向，避免后续协作中出现无核心、无目标的内耗；
    2. 成员自主选择小组，而非被动分配，能大幅提升后续参与的积极性，减少抵触感；
    3. 流程简单清晰，能在短时间内完成分组，适配本次讨论的时长限制；
    4. 主题前置的方式，能让每个小组从一开始就聚焦明确的方向，为后续讨论打下基础；并且采用“坚定主题或兴趣前置（至少知道大家的兴趣点到底在哪里，主题相近之后再来决定人怎么靠近）”的逻辑：先让大家明确兴趣/主题相近，再决定成员靠近与分组归属。
    二、具体操作
    步骤1：规则说明（约5分钟）
    由主持人向全体成员说明本次分组的目标、流程和规则：
    - 分组目标：在1.5小时内完成分组，形成3个有明确主题、有负责人的小组；
    - 分组逻辑：坚定主题或兴趣前置（至少知道大家的兴趣点到底在哪里，主题相近之后再来决定人怎么靠近），再由成员自主选择加入并完成队长与小组的匹配；
    - 人数要求：每组人数控制在3-4人
    步骤2：主题/兴趣前置与成员靠近（约25分钟）
    1. 主题/兴趣前置说明：主持人先行抛出本次讨论的主题方向或征集兴趣点（确保大家至少知道彼此的兴趣点与主题相近之处），并明确每个主题方向的讨论范围与预期产出；
    2. 队长自荐与主题/兴趣对齐：现场成员自愿报名成为小组队长，队长需说明其希望承接的主题方向/兴趣点，并简要说明该方向下后续讨论/协作目标与自己能承担的工作（如协调分工、跟进进度、对外沟通等）。自荐人数控制在4-5人以内，避免选择过于分散；
    3. 队长限时陈述：每位自荐队长用2分钟完成陈述，内容包含3点：
    - 想要带领的小组的核心主题/方向（与前置的兴趣/主题相近）；
    - 小组后续的讨论/协作目标；
    - 自己作为队长能承担的工作（如协调分工、跟进进度、对外沟通等）；
    4. 快速答疑：每位队长陈述结束后，回应成员1个简短问题（30秒内），帮助成员进一步确认主题/兴趣匹配程度。
    步骤3：队长确定与小组登记（约20分钟）
    1. 成员靠近与登记：所有非自荐成员，根据队长的陈述与前置的主题/兴趣方向，选择意向小组，进行登记（可采用举手、意向投票方式）；
    2. 人数均衡调整：若某小组报名人数超过设定上限，意向成员开启个人陈述，每人时间1分钟，讲述个人想法和能为团队带去什么，由队长进行反选；超出的成员可在主持人引导下，选择其他未满员的小组，或与队长协商调整主题/兴趣匹配，吸纳更多成员。
    步骤4：最终确认与小组对齐（约20分钟）
    1. 主持人公布最终分组结果，确认每个小组的成员、队长、主题方向；
    2. 每个小组用10分钟快速内部对齐，确认临时分工（如记录员、后续讨论的发言人）；
    3. 兜底协调：若有未加入小组的成员，或未被选上的自荐队长，由主持人协调加入未满员的小组，确保全员都有归属。
